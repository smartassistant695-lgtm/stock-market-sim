Data Builder

Researcher only. Downloads 3 trading days of real 1-minute prices from Alpaca and makes the experiment's data file, stocks.json.

Settings

The file uses the last 3 back-to-back full trading days on or before the end date. Leave it blank for the most recent days.

Put the file on the website

  1. Tap Download stocks.json. On an iPad the file goes to the Files app, in Downloads. If it is named stocks (1).json, rename it to stocks.json.
  2. Open this project's repository on github.com and sign in.
  3. Open the public folder, then the data folder.
  4. Click Add file > Upload files.
  5. Choose stocks.json. It replaces the old file.
  6. Click Commit changes.
  7. Vercel puts the new file online automatically in about a minute. Then the "Placeholder data" warning on the researcher screen disappears.
